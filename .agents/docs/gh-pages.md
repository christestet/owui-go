# Documentation Pipeline: Cobra CLI -> Astro Starlight -> GitHub Pages

Reference for how the `owui` documentation site is generated, built and
deployed. The site lives at <https://christestet.github.io/owui-go/>.

## Stack

- **Generator**: `internal/tools/docgen` walks the Cobra command tree and emits
  one Markdown page per command with Starlight-compatible YAML frontmatter
  (`title`, `description` only).
- **Site**: Astro + Starlight under `docs/` (`docs/package.json`,
  `docs/astro.config.mjs`). `base` is `/owui-go` so the project page works from a
  GitHub Pages sub-path.
- **Deployment**: GitHub Actions native Pages artifact upload (no `gh-pages`
  branch). See `.github/workflows/docs.yml`.

## Layout

```
docs/
  astro.config.mjs            # Starlight config (title, sidebar, base path)
  package.json                # Astro + @astrojs/starlight + sharp
  src/
    content.config.ts         # docsLoader + docsSchema
    content/docs/
      index.mdx               # splash homepage
      overview.md install.md usage.md configuration.md
      reference/cli/          # GENERATED by `make docs-cli` (gitignored)
```

## How it works

1. `make docs-cli` runs `docgen` with
   `-out ./docs/src/content/docs/reference/cli -format markdown -frontmatter`,
   regenerating the CLI reference pages. These are gitignored and rebuilt in CI.
   `DisableAutoGenTag` is set so there are no timestamps (avoids cache churn).
2. The Starlight sidebar autogenerates the "Reference" group from
   `reference/cli`, so new commands appear automatically.
3. `make docs-site` (or `cd docs && npm run build`) builds the static site to
   `docs/dist`.
4. CI (`.github/workflows/docs.yml`) on push to `main`: set up Go -> `make
   docs-cli` -> set up Node -> `npm ci` -> `npm run build` ->
   `upload-pages-artifact` (path `docs/dist`) -> `deploy-pages`. The build job
   also runs on PRs touching `docs/**`; the deploy job only runs on push to
   `main`.

## Local development

```sh
make docs-deps   # npm ci in docs/
make docs-dev    # generate CLI reference, then astro dev (live reload)
make docs-site   # generate CLI reference, then astro build
```

## Customization points

- Sidebar / title / `base`: `docs/astro.config.mjs`.
- Frontmatter shape: `prep` closure in `internal/tools/docgen/main.go` — keep it
  within Starlight's `docsSchema` (do not re-add `slug`/`tags`).
- Guide pages: add Markdown under `docs/src/content/docs/` and reference the
  slug in the sidebar.
